# Zeichnungspaket 01 – Gesamtboxen

Dieses Dokument beschreibt die Gesamtbauform der beiden Katzenboxen als erste technische Text-/ASCII-Zeichnung.

Status: Planungsstand / erste Blaupause. Maße können nach echtem Holz, Napfmaßen und Türtests noch angepasst werden.

---

# Übersicht

Es gibt zwei Boxgrößen:

| Box | Zweck | Außenmaß |
|---|---|---:|
| Box A | kleinere/Bengal-Mix-Katze | 100 x 60 x 60 cm |
| Box B | Maine-Coon-/Largebox | 120 x 65 x 65 cm |

Beide Boxen haben denselben Grundaufbau:

- kompletter Klappdeckel oben
- Eingang vorne links oder leicht links-mittig
- seitliche Schiebetür läuft nach rechts in eine Türtasche
- Liegebereich hinten links
- Futterbereich hinten rechts
- erhöhte Futterplattform mit herausnehmbarem Einsatz
- separates Technikfach empfohlen
- Lüftung oben/hinten/seitlich

---

# Zeichnungslegende

```text
E  = Eingang / RFID-Türöffnung
T  = Türtasche / Schiebetür fährt hier hinein
L  = Liege-/Chillbereich
F  = Futterpodest / Futterbereich
TF = Technikfach, separat oder seitlich angebaut
```

- Vorne genügend freie Zone lassen, damit die Katze ein-/aussteigen kann.

# Gemeinsame Anforderungen für beide Boxen

## Deckel

```text
- kompletter Klappdeckel oben
- 2–3 Scharniere hinten
- Deckelstütze/Kette/Gasdruckfeder empfohlen
- optional Filz/Moosgummi gegen Klappern
```

## Lüftung

```text
- Lüftungsöffnungen oben/hinten/seitlich
- keine komplett luftdichte Box
- Öffnungen so wählen, dass keine Pfoten gefährlich hängen bleiben
```

## Futterbereich

```text
- erhöhtes Podest
- herausnehmbarer, abwischbarer Einsatz
- 2 Kerbl Edelstahlnäpfe pro Box eingebaut
- 2 Ersatznäpfe pro Box
- kleiner Rand gegen Futterreste
- Dübel/Zapfen-Fixierung gegen Verrutschen
```

## Türbereich

```text
- seitliche Schiebetür läuft innen hinter der Front
- Tür öffnet nach rechts
- Türtasche muss zugänglich und wartbar bleiben
- Türschiene vor Futter/Fell schützen
- Schließkante weich ausführen
```

## Technikfach

```text
- Elektronik getrennt vom Katzenraum
- ideal außen seitlich oder hinten oben angebaut
- zugänglich für Wartung
- keine losen Kabel im Katzenraum
```
