# Teileliste / Parts List

Status: Vorlage. Diese Liste wird finalisiert, sobald alle Module vollständig entschieden sind.

## Mengenlogik

Das Projekt besteht aus zwei Boxen:

- Box A: Standardbox
- Box B: Largebox / Maine Coon

Viele Elektronikteile werden pro Box einmal benötigt und daher insgesamt doppelt gekauft.
