# Cat Home – RFID Katzen-Futterhaus

Projektziel: Zwei große Holzboxen für zwei Katzen. Jede Katze bekommt per RFID/NFC-Halsbandtag Zugang zu ihrer eigenen Box. Innen gibt es eine Liege-/Chillfläche, eine erhöhte Futterplattform mit Nass- und Trockenfutter sowie eine leise seitliche Schiebetür.

## Grundidee

- 2 getrennte Boxen, eine pro Katze
- RFID/NFC-Halsbandtag statt implantiertem Chip
- seitliche Schiebetür mit 12V-Getriebemotor
- Sensoren verhindern Einklemmen
- Katze kann von innen immer raus
- oben kompletter Klappdeckel zum Reinigen
- leicht zu reinigender Futterbereich mit herausnehmbarem Einsatz

## Projektrollen

- Holzbau/Mechanik: Box, Podest, Schiebetür, Schienen, Halterungen
- Elektronik/Software: ESP32, RFID, Sensoren, Motorsteuerung, Sicherheitslogik
